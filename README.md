# SuperXtra - Página de ofertas

## Descripción

SuperXtra es un proyecto de desarrollo web que consiste en una página estática inspirada en un supermercado. Su objetivo es presentar productos y promociones mediante una interfaz sencilla y visualmente organizada.

## Tecnologías utilizadas

- HTML5: estructura y contenido de la página.
- CSS3: estilos y diseño personalizado.
- Bootstrap 5.3.3: componentes y distribución adaptable.

## Características

- Barra de navegación con logo.
- Campo de búsqueda visual.
- Carrusel de imágenes promocionales.
- Sección de ofertas semanales FULLXTRA.
- Cuatro tarjetas de productos.
- Pie de página con identidad de SuperXtra.
- Adaptación básica a dispositivos móviles.

## Productos presentados

1. Chorizos Berard.
2. Cheese Puff.
3. Papel Higiénico Cuidado Completo Scott.
4. Ketchup Maggi.

## Ejecución

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto.
3. Ejecutar `index.html` en un navegador web.

## Estado del proyecto

Proyecto web estático. Los botones de búsqueda y de añadir al carrito son elementos visuales y todavía no cuentan con funcionalidades interactivas.
